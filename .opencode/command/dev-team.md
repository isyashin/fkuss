Разработка командой. Вход от пользователя: $ARGUMENTS

Маршрутизация моделей (только Free):
- план и сложные решения — `architect` (Spark 1.3)
- основной код — `backend-dev` (Spark 1.2)
- деньги/бонусы/доставка/биллинг — `billing-tdd` (Spark 1.2, навык test-driven-development)
- мелочь пачками — `bulk-worker` (Nemotron 3.5 Lightning)
- визуал/mobile — `visual-qa` (MiMo V2.5, read-only)
- второе мнение по диффу — `reviewer` + Nemotron 3 Ultra как консультант
- формулы/тарифы как справка — Ling Fin; smoke-пробы — Big Pickle (без секретов и денег)

Порядок:
1. Прочитай `docs/PLAN.md` (статусы волн) и проверь `git status`.
2. Делегируй декомпозицию `architect`. Деньги всегда отдельным пакетом в `billing-tdd`.
3. Запускай пакеты параллельно через Task (максимум 2 кодирующих — E2E строго `workers: 1`):
   каждому пакету свой worktree (`git worktree add wt/<пакет>`).
4. После готовности всех пакетов — прогони `reviewer` по диффу каждого.
5. Интеграционные тесты — только через `template/scripts/test-with-db.sh`
   (нужен Docker); E2E — серийно, `npx playwright test`.
6. Обнови `docs/PLAN.md` в том же наборе изменений.
7. Отчёт пользователю: пакеты, тесты (юнит/интеграция/E2E отдельно),
   что осталось, нужен ли выбор пользователя.

Запрещено:
- трогать ветку и worktree `codex/print-materials` (её доделывает Codex);
- коммитить секреты (только имена в `secrets/sites/<slug>.env`);
- пушить без явного разрешения владельца.
