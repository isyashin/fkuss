# Исследование и источники

Открытый поиск используется для фактов о ресторане, а не для заполнения пробелов
догадками.

## Приоритет источников

1. Данные владельца и официальные документы.
2. Официальный сайт и подтверждённые страницы ресторана в соцсетях.
3. Карточка ресторана в Яндекс.Еде — меню, цены, модификаторы, доступность.
4. Карты и каталоги — только как дополнительное подтверждение контактов.

При расхождении не выбирай вариант молча. Покажи оба значения, ссылки и дату
проверки, затем попроси владельца решить.

## Что фиксировать

Создай `source-report.json`:

```json
{
  "checkedAt": "2026-09-21T12:00:00Z",
  "sources": [
    {
      "url": "https://example.ru/",
      "kind": "official-site",
      "fields": ["phone", "address", "workHours"]
    }
  ],
  "confirmed": ["name", "phone", "address"],
  "unresolved": ["email"],
  "imageRights": "provided-by-owner"
}
```

Ссылки должны вести на просмотренные страницы, а не на поисковую выдачу.
Не копируй отзывы и длинные описания. SEO и описания блюд формулируй заново
по подтверждённым фактам.

## Контакты

Телефон, адрес и часы считаются подтверждёнными, если их дал владелец или они
совпадают в официальном источнике и ещё одном независимом источнике. Email,
которого нет в официальных источниках, нужно запросить у владельца. До этого
email-канал остаётся выключенным.
