# CHANNELS.md — каналы приёма заказов

Как получать токены и подключать каждый канал. Настройка каналов сайта —
в админке (значения секретов — в `secrets/sites/<slug>.env`).

## Telegram

1. В Telegram открыть @BotFather → `/newbot` → получить токен
   (`TELEGRAM_BOT_TOKEN`).
2. Создать группу для заказов, добавить туда бота администратором.
3. Узнать chat_id группы (написать в группу, затем
   `https://api.telegram.org/bot<TOKEN>/getUpdates` → `chat.id`).
4. В админке: включить Telegram, ввести chat_id. Токен — в
   `secrets/sites/<slug>.env` как `TELEGRAM_BOT_TOKEN`.

Формат сообщения о заказе: состав и количество блюд, суммы, тип
(доставка/самовывоз), адрес, контакты, комментарий, способ оплаты.

## MAX

- Документация: https://dev.max.ru/docs-api
- REST API: `https://platform-api.max.ru`, лимит ~30 запросов/сек.
- ⚠️ Подключение доступно юрлицам, ИП и самозанятым — резидентам РФ.
- Регистрация бота через кабинет разработчика MAX → токен
  (`MAX_BOT_TOKEN`) + chat_id чата ресторана.

## Email

- Отправка через общий SMTP проекта (см. DEPLOY.md): коды входа гостей
  и уведомления о заказах.
- В админке ресторан указывает только адрес получателя заказов.
- DKIM/SPF/DMARC на общем домене настроены один раз.

## WhatsApp

- MVP: кнопка `https://wa.me/<номер>?text=<состав заказа>` на странице
  подтверждения заказа. Клиент сам отправляет сообщение ресторану.
- В админке: номер WhatsApp в международном формате без «+» в ссылке.
- Полноценный приём заказов в WhatsApp (Business API через провайдера) —
  вне MVP, платно и с модерацией шаблонов.
