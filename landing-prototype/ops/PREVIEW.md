# Предварительная версия дизайна

Публичный адрес для обсуждения: https://design.fkuss.ru/.
Это отдельное развёртывание ветки codex/landing-design-preview. Ветка main
и контейнер основного лендинга не переключаются до согласования дизайна.

## Изоляция

- Compose: compose.preview.yaml, проект/контейнер/сеть fkuss-landing-preview.
- Только localhost:4187; Caddy обслуживает отдельный host design.fkuss.ru.
- Релизы: /home/ilya/resto/landing-preview/releases/<commit>/landing-prototype.
- Указатель текущего релиза: /home/ilya/resto/landing-preview/current.
- Приватные файлы: /home/ilya/resto/secrets/landing-preview/.
- База заявок своя; рабочие заявки и сессии в предпросмотр не копируются.
- Учётные данные администратора могут использовать тот же scrypt-хеш,
  но лежат отдельной копией в приватной папке предпросмотра.
- FKUSS_LANDING_PREVIEW=1 включает noindex в HTML и заголовках,
  robots.txt запрещает обход всего сайта, sitemap.xml возвращает 404.
- Форма помечена как тестовая; подтверждение не обещает обратный звонок.

Предпросмотр сохраняет production-режим: Secure-cookie, кеширование,
тот же ограниченный пользователь контейнера и read-only root filesystem.
Не используйте основной compose.yaml или общий scripts/update.sh для
развёртывания этой версии.

## Обновление и откат

Из GitHub извлекается конкретный проверенный коммит в собственный каталог
релиза. Собирается только образ предпросмотра; тесты запускаются в
закреплённом Node-образе. Перед добавлением host-блока сохраняется Caddyfile
и снимок ID работающих контейнеров. Caddyfile проверяется через adapt/validate;
существующие маршруты должны остаться эквивалентными. Применение — атомарная
замена файла и graceful reload, с возвратом сохранённого файла при сбое.

Откат приложения переключает только релиз и контейнер предпросмотра.
Не удаляйте данные основного лендинга, общие сети, образы и контейнеры
ресторанов. Перед отключением preview-маршрута сравните активный Caddyfile
со снимком: нельзя затирать изменения, сделанные после публикации.
