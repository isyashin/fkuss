# Issue #51: Предзаказ — настройки слотов есть, выбора слота в чекауте нет
GitHub: isyashin/fkuss#51
## Симптом
Настройки → предзаказ: enabled=true, слоты [10:00, 10:30, 11:00] в БД, но в чекауте витрины поля выбора времени предзаказа нет.
## Задача
Изучи схему (settings.preOrder: enabled, slots, сутки/лимиты?) и чекаут. Реализуй UX по смыслу существующих настроек:
- если preOrder.enabled и слоты заданы → в чекауте (доставка и самовывоз, по смыслу настройки) показывать выбор: «Как можно скорее» (по умолчанию) или слот времени (сегодня/завтра если заложено в настройках);
- выбранный слот сохранять в заказ (поле в схеме есть? если нет — миграция prisma + отображение в админ-заказе);
- серверная валидация: слот из списка разрешённых, прошедшие слоты отклонять/не предлагать;
- в админке заказа показывать выбранное время.
Следуй существующим паттернам проекта (zod, {ok,error}, revalidate). Если в настройках уже есть поля, которые не используются — задействуй их, а не выдумывай новые.
## Acceptance
- Гость выбирает слот → заказ создаётся со слотом → виден в админке.
- Выключенный предзаказ → чекаут как раньше.
- Тесты зелёные + unit на валидацию слотов. Минимум комментариев.
